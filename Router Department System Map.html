If something’s down — start here

  • Dashboard blank or stale: open …/exec?format=json (#5). If it errors, confirm sheets #3 and #4 are still shared with stickersquicktesting@gmail.com.
  • New cuts not appearing: the shop logger (#2) isn’t writing to the Job Log — check the router PC / logging software.
  • Queue, sizes, or WOs wrong/empty: the schedule sheet (#4) moved, was renamed, or lost read access for the Apps Script account.
  • A code change didn’t go live: GitHub → Actions tab (#6) for a failed run. Pages OIDC hiccup → re-run with “Run workflow” (workflow_dispatch), NOT “re-run failed jobs” (that duplicates the Pages artifact).
  • clasp / Apps Script login broke: run clasp login with @google/clasp@2.4.2, then update the CLASPRC_JSON repo secret.
